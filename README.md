# cositeca

The old address of the Cositálogo, kept so shared links keep working.
`christt105.github.io/cositeca` now opens
https://cositalogo.christt105.workers.dev/, keeping the title or search in
the `#/...` route (`redirect.js`). `sw.js` clears and unregisters the
service worker of the old installable app.

The Cositálogo itself lives in
[christt105/cositalogo](https://github.com/christt105/cositalogo).
Published with GitHub Pages from the root of `main`.
